# lovable-porting
Repo containing context for porting lovable skills to my hopsakee.top server.

## Where to look

- **[`PORT-SCOPE.md`](PORT-SCOPE.md)** — which apps get ported, in what order,
  and what was decided about each. Start here; it is the standing answer and it
  overrides the plan document on scope.
- **[`PORTING-PLAYBOOK.md`](PORTING-PLAYBOOK.md)** — how to do a port. Every
  claim is marked VERIFIED (a real port confirmed it) or ASSUMED (it came from
  planning). Read before starting an app.
- **[`MIGRATION-PLAN.md`](MIGRATION-PLAN.md)** — the original design and the
  dated status sections. History, not the current scope.
- **[`learnings/`](learnings)** — one file per ported app: what actually
  happened, including what went wrong.
